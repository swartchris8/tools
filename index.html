Hungarian Letter Studio

Turn handwritten Hungarian letters into editable text. Refine a prompt from a verified transcript, then evaluate it on unseen letters with character and word error rates, token usage, and estimated cost.

Open Letter Studio →

Import images or a ZIP. Calls go directly to OpenAI or Anthropic when you run an action. Your key stays in tab memory; export your work before closing.

Tools to run locally

These Python scripts run on your computer with uv. They are downloads, not browser apps.

Audio → text

Whisper transcription

Transcribe audio or video with a local Whisper model and save the text.

uv run transcribe.py recording.m4a

Download script

Audio + speakers

Whisply interface

Launch the Whisply web interface locally for transcription and speaker diarization.

uv run whisply_script.py

Download script

Video + audio

Media downloader

Download media with yt-dlp, with an option to extract audio.

uv run yt-dlp-script.py "URL"
